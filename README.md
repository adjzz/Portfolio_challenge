Portfolio — Ralf Adjay F. Estenor

Short Description

This is a personal portfolio website designed to showcase my work, skills, and profile. It features a modern, animated UI with floating background shapes, typing text effects, interactive profile images, and a responsive design suitable for both desktop and mobile screens.

The site includes an intro animation, a monitor mockup, and side buttons for easy navigation. It is visually engaging while maintaining a clean and professional look.

## Technologies Used
- HTML5 – Markup structure for pages  
- CSS3 – Styling, animations, gradients, and responsive layouts  
- Flexbox – For responsive and flexible layout design  
- CSS Animations & Keyframes – For intro screen, floating shapes, profile image effects, and monitor animation  
- Responsive Design Techniques – Media queries and scalable units (`clamp`, `%`)  
- Optional JavaScript – For interactivity if needed (typing effects, navigation highlighting)
